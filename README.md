# Namorix Brand Assets

![Namorix Brand](brand.png)

Official brand assets for the **Namorix** ecosystem.

## Files

| File | Description |
| :--- | :--- |
| `logo.ai` | Adobe Illustrator master — full logo |
| `logo.svg` | Exported SVG — full logo |
| `brand.ai` | Adobe Illustrator master — brand symbol |
| `background.ai` | Adobe Illustrator master — background/graphic element |
| `background.svg` | Exported SVG — background/graphic element |

Edit the `.ai` (Illustrator) source files, then export to SVG.
